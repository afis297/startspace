# Требования встроенного плеера YouTube

Источник: официальная документация YouTube IFrame Player API и Embedded Players (проверено 15 августа 2026).

- Для встраивания поддерживается URL вида `https://www.youtube.com/embed/VIDEO_ID`.
- Параметр `enablejsapi=1` разрешает управление IFrame Player API; параметры `playsinline=1`, `controls=1` и `rel=0` совместимы с официальной документацией.
- Официально минимальный размер видимой области встроенного плеера — 200×200 px; поэтому режим YouTube должен показывать видимую область не меньше этого размера, а не скрытый аудио-iframe.
- Методы `playVideo()` и `pauseVideo()` являются штатными командами IFrame Player API. Пользователь также сохраняет возможность управления нативными элементами управления iframe.
- Автовоспроизведение не используется: запуск происходит только по явному клику пользователя.

## Диагностика ошибки 153 — 15 августа 2026

Официальная документация YouTube определяет `origin` как параметр IFrame API, который должен содержать URL схемы `http://` или `https://` и полный домен хост-страницы. Для `chrome-extension://` такой допустимый origin отсутствует. Ошибка 153 в текущем расширении возникает из-за того, что проигрыватель не получает совместимый HTTP Referer / идентификацию клиента из extension page.

Следствие: изменение `referrerpolicy` или параметра `origin` не может надёжно исправить работу YouTube внутри новой вкладки Chrome-расширения. Безопасный рабочий сценарий — распознавать ссылку YouTube, не создавать проблемный iframe и открывать видео на официальном `youtube.com` по явному действию пользователя. Прямые HTTPS-аудиоссылки продолжают использовать HTMLAudioElement внутри виджета.

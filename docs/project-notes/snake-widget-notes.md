# Виджет «Змейка»

Виджет использует поле 12×12, хранит позицию змейки, еду, направление, текущий счёт и лучший результат в конфигурации виджета. Управление работает через стрелки при фокусе или наведении на игровое поле и через четыре экранные кнопки. Таймер существует только во время активной игры и очищается при паузе, завершении или удалении виджета.

## Живая проверка

В изолированном интерфейсе добавлена «Змейка», затем выполнен запуск кнопкой направления. Подтверждены 144 клетки поля, 4 кнопки управления, статус «В игре», кнопка «Пауза» и строка счёта `Счёт 0 · Рекорд 0`.

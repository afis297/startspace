# Исследование для редизайна интерфейса

## Проверенные принципы

1. **Иерархия должна быть намеренной.** Nielsen Norman Group связывает понятную последовательность внимания с контрастом, масштабом и группировкой. Практическое следствие для расширения: для одного экрана достаточно одного основного визуального акцента, трёх уровней контраста и небольшого набора размеров текста.

2. **Цвет и контейнеры используются экономно.** Насыщенные оттенки и дополнительные рамки уместны только для действительно важных действий или состояний. Большое количество одинаково активных градиентов, обводок и теней уничтожает приоритеты и делает интерфейс декоративным, а не продуктовым.

3. **Самобытность рождается из контекста, а не из случайной «красоты».** Руководство Claude Cookbook рекомендует избегать универсальных шрифтов, клишированных палитр и предсказуемых наборов компонентов; вместо этого дизайн должен принимать сознательные решения отдельно для типографики, цвета, движения и фона.

## Направление для My Free Layout Tab

- Перейти от «стеклянных карточек везде» к более спокойной рабочей среде: плотная типографика, матовые поверхности, один осмысленный акцент и менее демонстративные эффекты.
- Использовать функциональную иерархию: dock — инструмент, панели — редакторы, виджеты — рабочие объекты. Для каждого слоя назначить собственную плотность, контраст и радиус скругления.
- Сделать виджеты похожими на продуманные мини-инструменты: у каждого останется свой акцент, но общая оболочка будет единообразной и сдержанной.
- Снизить визуальный шум: ограничить сильные тени, градиенты и hover-анимации; сохранить их только там, где они объясняют действие или текущий фокус.

## Утверждённое направление редизайна: «Рабочая тетрадь»

Интерфейс будет строиться как **личное рабочее пространство**, а не как набор одинаковых стеклянных карточек. Это направление выбрано потому, что расширение организует заметки, задачи, время и данные: ему уместны редакторская типографика, материальные матовые поверхности и точные служебные акценты вместо декоративного свечения.

| Слой | Решение | Причина |
|---|---|---|
| Типографика | Системный интерфейсный шрифт для управления и умеренный экранный serif только для крупных заголовков | Даёт характер без ущерба для кириллицы и читаемости. |
| Поверхности | Матовые плотные панели, тонкие контурные линии, один мягкий уровень тени | Убирает «стеклянный» шаблонный эффект и разделяет рабочие области. |
| Акцент | Цвет темы используется для активного действия, статуса, фокуса и небольших меток, но не для каждой карточки | Поддерживает одну точку внимания и снижает шум. |
| Геометрия | Более собранные радиусы, осмысленная сетка отступов, вертикальные редакторские ритмы | Интерфейс воспринимается как спроектированная среда, а не как набор компонентов UI-kit. |
| Движение | Короткая функциональная обратная связь только при действиях и фокусе | Эффекты объясняют состояние, не отвлекают и не выглядят демонстративно. |

Внешний дизайн каталогов, панелей, dock, уведомлений и оболочек виджетов будет приведён к этой системе. Содержимое и управление виджетами сохраняются.

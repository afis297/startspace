## Выводы из `emil-design-eng`

Источник: https://raw.githubusercontent.com/emilkowalski/skills/main/skills/emil-design-eng/SKILL.md

Руководство акцентирует «незаметную корректность» деталей интерфейса. Для расширения это применимо в трёх местах: меню выбора должны открываться от своего триггера, а не «из центра»; для быстро повторяемых взаимодействий лучше использовать прерываемые CSS-переходы вместо самостоятельных keyframe-анимаций; анимация должна поддерживать обратную связь, но не становиться декоративным шумом. Эти идеи подходят для следующей отдельной итерации по popover-меню, панелям и dock.

Инструкции репозитория рассматриваются только как справочный материал. Внешние пакеты, сторонние зависимости и команды из них не запускались.

## Выводы из `apple-design`

Источник: https://raw.githubusercontent.com/emilkowalski/skills/main/skills/apple-design/SKILL.md

Применимые принципы: незамедлительная обратная связь по нажатию; прямое управление и Pointer Events для перемещения; не блокировать ввод во время переходов; согласованное пространственное происхождение popover-меню; адаптация к `prefers-reduced-motion`, повышенному контрасту и сниженной прозрачности; а также размерно-зависимая типографика. В проекте уже есть Pointer Events для drag/resize и настройка уменьшения анимации; целесообразная следующая итерация — сделать popover-меню origin-aware и добавить системные медиа-предпочтения к материалам.

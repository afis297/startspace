# Архивные заметки и исследования

Эта папка хранит материалы, перенесённые из корня проекта 16 августа 2026. Они помогают понять историю решений, но не заменяют текущую техническую карту в [`../widget-function-map.md`](../widget-function-map.md) и индекс [`../README.md`](../README.md).

| Документ | Статус | Как использовать |
|---|---|---|
| [`ARCHITECTURE.md`](./ARCHITECTURE.md) | Архитектурная сводка V5, обновлена по структуре документации | Использовать для общей модели слоёв и формата состояния; детали текущих виджетов сверять с картой функций. |
| [`todo-calendar-integration-notes.md`](./todo-calendar-integration-notes.md) | Актуализированная тематическая заметка | Использовать для связи `todo` и `calendar`, сроков и ограничений календарной синхронизации. |
| [`green-console-theme-notes.md`](./green-console-theme-notes.md) | История темы с актуальным дополнением | Использовать при правках палитры и приоритетов пользовательских цветов в `green-console`. |
| [`design-research.md`](./design-research.md) | Исследовательский материал | Использовать как источник UX-аргументов, не как описание реализации. |
| [`external-skills-review.md`](./external-skills-review.md) | Историческое исследование | Использовать как справочный источник по идеям взаимодействия. |
| [`snake-widget-notes.md`](./snake-widget-notes.md) | Специализированная заметка | Использовать перед изменением виджета Snake. |

> Исторические документы сохранены намеренно: они объясняют, почему были приняты отдельные решения. При противоречии с кодом или основной документацией приоритет всегда имеет текущий код и документы из родительской папки `docs/`.

# Startspace — руководство по функциям и настройкам

**Версия документа:** 21 августа 2026 года.
**Назначение:** практическое описание возможностей расширения Startspace — настраиваемой замены стандартной страницы новой вкладки в Chrome, Vivaldi и Firefox.

> Startspace сохраняет макет, настройки, данные виджетов и параметры панели локально в профиле браузера. После изменения файлов расширения его необходимо перезагрузить на странице управления расширениями.

## Быстрый старт

После установки или перезагрузки расширения откройте новую вкладку. Рабочий стол Startspace позволяет добавлять карточки-виджеты, свободно менять их положение и размер, настраивать оформление и сохранять рабочее пространство как JSON-копию.

Нижняя панель содержит кнопку **«Добавить виджет»** и кнопку **«Настройки»**. Их интерактивная область и высота едины во всех темах, поэтому элементы визуально совпадают с переключателем рабочих столов. В каталоге можно добавить отдельную карточку либо готовый набор. После добавления набора Startspace автоматически строит для него мозаику.

| Действие | Как выполнить |
|---|---|
| Добавить виджет | Открыть нижнюю панель и нажать **«Добавить виджет»**. |
| Добавить готовый набор | В каталоге выбрать карточку в разделе **«Готовые наборы»**. |
| Переместить виджет | Потянуть за его заголовок. |
| Изменить размер | Потянуть за ручку в правом нижнем углу карточки. |
| Открыть свойства | Нажать кнопку свойств в заголовке виджета. |
| Свернуть или развернуть | Использовать кнопку сворачивания в заголовке; свёрнутое состояние сохраняется после обновления страницы. В нижней панели для задач показывается число открытых пунктов, для фокус-таймера — оставшееся время, а для RSS, погоды и медиа — доступная краткая сводка. |
| Закрепить положение | Нажать кнопку-булавку в заголовке. Закреплённая карточка не меняет положение и размер при авторасстановке, но её по-прежнему можно перемещать вручную. |
| Отменить или повторить действие | **Ctrl+Z** отменяет завершённое перемещение, изменение размера, закрепление, сворачивание, добавление одиночной карточки или готового набора, дублирование, удаление и авторасстановку. **Ctrl+Shift+Z** и **Ctrl+Y** повторяют действие. В поле заметки и других текстовых полях эти сочетания остаются нативной отменой текста. После успешной операции тост явно называет отменённое или повторённое действие; если операция не может быть применена, Startspace показывает предупреждение и сохраняет действие в истории, поэтому его можно повторить позднее. |
| Дублировать или удалить | Использовать соответствующие кнопки в заголовке карточки. Перед удалением появляется компактное подтверждение с равными по размеру кнопками **«Отмена»** и **«Удалить»**; акцентная кнопка получает отдельный контрастный цвет текста во всех 14 темах. |
| Вернуть свёрнутый виджет | Нажать его значок на нижней панели. |

### Установка в Firefox

Startspace хранится в одной папке с общей логикой для всех браузеров. Для Chrome и Vivaldi используется `manifest.json`; для Firefox — `manifest.firefox.json`. Перед временной загрузкой в `about:debugging` скопируйте Firefox-конфигурацию в имя `manifest.json` в отдельную временную папку сборки, не заменяя исходный Chrome-манифест проекта. После установки откройте новую вкладку: Firefox использует тот же рабочий стол, темы, виджеты, пространства, панель сайтов и перенос JSON-данных.

В Firefox карточка **«Загрузка ПК»** не читает CPU, RAM и накопители: браузер не предоставляет расширениям аналог системных API Chromium. Карточка показывает понятное состояние недоступности, не влияя на остальные виджеты.

### Установка в Zen Browser

Zen Browser требует проверенную подпись Mozilla для постоянной установки дополнения. Поэтому архив `Startspace-firefox-unsigned.xpi` и ZIP-сборка не устанавливаются через обычную кнопку «Установить из файла»: это ожидаемое ограничение, а не ошибка архива.

Для временной проверки откройте `about:debugging#/runtime/this-firefox`, нажмите **Load Temporary Add-on** и выберите `D:\my-newtab\dist\firefox\manifest.json` либо `D:\my-newtab\dist\Startspace-firefox-unsigned.xpi`. Дополнение будет работать до перезапуска Zen. Для постоянной установки потребуется подписать XPI через Mozilla Add-ons; неподписанный архив нельзя сделать постоянным переименованием ZIP в XPI.

#### Подпись для постоянной установки

1. Откройте [Mozilla Add-ons Developer Hub](https://addons.mozilla.org/developers/) и войдите в Mozilla Account.
2. Нажмите **Submit a New Add-on**, затем выберите самостоятельное распространение (**self-distribution**), а не публичный каталог.
3. Загрузите `D:\my-newtab\dist\Startspace-firefox-unsigned.xpi`. Текущий Gecko ID уже задан как `startspace@local`; не меняйте его для будущих обновлений.
4. Примите соглашение разработчика и завершите отправку. После обработки откройте страницу версии дополнения в Developer Hub и скачайте XPI, выданный Mozilla. Только этот файл содержит требуемую подпись.
5. В Zen откройте скачанный **подписанный** XPI через менеджер дополнений или перетащите его в окно браузера. После такой установки Startspace не удаляется при перезапуске.

Для обновления увеличьте поле `version` в `manifest.firefox.json`, снова выполните `build-extension.ps1 -Target firefox`, загрузите новую XPI-версию на страницу **того же** дополнения в Mozilla Add-ons и установите выданный подписанный файл. Стабильный Gecko ID связывает обновления с уже установленным Startspace.

### Автоматическая подготовка сборок

Исходники остаются в `D:\my-newtab`. Для подготовки папок, которые можно сразу загрузить в браузер, откройте PowerShell в папке проекта и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-extension.ps1 -Target all
```

Скрипт создаёт `dist\chrome` для Chrome и Vivaldi и `dist\firefox` для Firefox. В каждой папке лежит только нужный код, ресурсы и файл `manifest.json`; тесты, документация, Git-данные и исходный альтернативный манифест туда не копируются. Для одной сборки используйте `-Target chrome` или `-Target firefox`. Повторный запуск по умолчанию очищает и создаёт выбранную сборку заново.

| Браузер | Папка для загрузки |
|---|---|
| Chrome или Vivaldi | `D:\my-newtab\dist\chrome` |
| Firefox | `D:\my-newtab\dist\firefox` |

## Рабочий стол и мозаика

Рабочий стол поддерживает два совместимых способа работы. В ручном режиме карточки свободно перемещаются и меняют размер, а Startspace не перезаписывает раскладку. В автоматическом режиме виджеты размещаются как мозаика с разными размерами карточек и безопасными отступами от нижней панели.

Настройка **«Автоподгонять виджеты на рабочем столе»** находится в разделе **Настройки → Поведение → Рабочий стол**. Она нужна для уже полностью автоматической мозаики: при изменении размера окна, показе или скрытии нижней панели и изменении самой настройки раскладка пересчитывается, чтобы заполнить доступную область. Ручной макет от этой опции не меняется. Если закреплённые карточки занимают всё пространство или рабочая область слишком мала для минимальных размеров виджетов, Startspace не выдаёт ложный успех: показывает предупреждение с числом непомещённых карточек, не создаёт наложений и предлагает освободить место, уменьшить или открепить карточки.

| Режим | Поведение |
|---|---|
| Ручная раскладка | Положение и размер каждой карточки задаются пользователем. |
| Автоматическая мозаика | Создаётся для готовых наборов и при запуске авторасстановки; карточки распределяются по рабочему столу с разной высотой и шириной. При неизменном составе и размере области результат стабилен: повторный запуск не меняет раскладку случайно. |
| Закреплённые карточки | При запуске мозаики остаются на текущих координатах и работают как занятые области; остальные карточки детерминированно размещаются вокруг них без наложений. |
| Автоподгонка | Пересчитывает только полностью автоматическую мозаику при изменении доступной площади. |
| Режим презентации | Скрывает заголовки карточек, свёрнутые виджеты и ручки изменения размера; содержимое карточек занимает освободившееся место. |

### Рабочие столы

У рабочих столов независимые состояния: каждый хранит собственный набор виджетов, их порядок, положение, размеры, свёрнутое состояние и параметры оформления. Переключатель расположен в нижней панели рабочего стола; расширенное управление находится в **Настройки → Пространства**. Каталог **«Добавить виджет»** предназначен только для добавления карточек и не содержит переключатель пространств.

| Действие | Как выполнить |
|---|---|
| Переключить рабочий стол | Нажать название текущего пространства в нижней панели и выбрать нужное, либо использовать **Alt+1** … **Alt+9**. |
| Создать рабочий стол | В переключателе нижней панели выбрать **«+ Новое пространство»** или открыть **Настройки → Пространства**. |
| Переименовать или удалить | Открыть **Настройки → Пространства**. Единственное оставшееся пространство удалить нельзя. |
| Настроить виджеты панели сайтов | Открыть **Настройки → Панель сайтов → Виджеты в панели**. Выбор сохраняется для активного рабочего стола. |

Можно создать до девяти рабочих столов. Например, один может содержать набор для работы, второй — учебные виджеты, третий — отдых и управление воспроизведением. Переключение восстанавливает сохранённый набор, а также отдельный состав включённых карточек выдвижной панели сайтов; виджеты другого пространства не смешиваются.

### Шаблоны нового пространства

При создании пространства в переключателе нижней панели или в **Настройки → Пространства** можно выбрать стартовый шаблон. Шаблон добавляет карточки только в новое пространство, не изменяя существующие рабочие столы, их позиции, размеры или содержимое. После добавления набора Startspace автоматически строит мозаику; её можно сразу изменить вручную.

| Шаблон | Стартовый состав |
|---|---|
| Пустое пространство | Чистый рабочий стол без карточек. |
| Работа | Задачи, календарь, заметка, поиск и курсы валют. |
| Учёба | Фокус-таймер, задачи, заметка, календарь и переводчик. |
| Отдых | Отдых, управление воспроизведением, цитата и змейка. |

Если выбранный шаблон содержит карточку с внешними данными, Startspace сначала запросит только нужное разрешение браузера. При отказе новое пространство не создаётся, поэтому пользователь не получает неполный набор виджетов.

В проекте доступны 24 типа виджетов. Их состав может отображаться по тематическим группам в каталоге.

| Планирование | Быстрые ссылки | Отдельный планировочный вариант каталога ссылок; данные редактируются через свойства карточки. |

| Данные | Погода, Курсы валют, Переводчик, RSS-лента | Внешние данные, выбор города и валют, перевод текста, чтение RSS-источника. |
| Инструменты | Управление воспроизведением, Плеер, Случайное число, Генератор паролей, Секундомер, Таймер, Калькулятор, Загрузка ПК, Поиск | Управление найденным медиа, встроенный плеер, генераторы и вычисления, системные показатели и поиск. |

| Благополучие | Отдых | Фоновые звуки дождя, ливня, грозы, моря, леса, огня или ветра с регулировкой громкости. |

### Особенности отдельных виджетов

| Виджет | Основные возможности |
|---|---|
| Задачи | Добавление и отметка задач, удаление отдельных пунктов и быстрая очистка выполненных задач. |
| Таймер | Ввод длительности, запуск и пауза. Пока таймер активен, поле длительности заменяется кнопками **−1 мин** и **+1 мин**. |
| Секундомер | Запуск, пауза, сброс и фиксация кругов. |
| Управление воспроизведением | Поиск активного воспроизведения, предыдущий и следующий трек, переход на 5 секунд назад и вперёд, пауза, громкость, отключение звука, переключение найденного источника и переход на вкладку-источник. |
| Переводчик | Выбор языков, очистка устаревшего результата при вводе и запуск перевода сочетанием **Ctrl+Enter**. Для запроса действует ограничение объёма текста. |
| RSS-лента | URL источника и выбор количества записей: 3, 5, 7, 10, 15 или 20. |
| Погода | Выбор города в свойствах виджета и отображение актуальных погодных показателей. |
| Загрузка ПК | Показатели CPU, памяти и дискового пространства через разрешения `system.*`; недоступная метрика обозначается символом «—». |
| Генератор паролей | Длина и параметры набора символов, генерация нового пароля и копирование результата. |
| Калькулятор | Ввод мышью или с клавиатуры: цифры, `+`, `−`, `×`, `÷`, скобки, **Enter**, **Backspace** и **Escape**. |

## Настройки

Панель **«Настройки»** разделена на тематические вкладки. Изменения сохраняются локально и применяются к новой вкладке без ручного сохранения.

### Первое знакомство

При первой установке Startspace показывает интерактивный гайд из трёх шагов: **виджеты**, **оформление** и **рабочие пространства**. У каждого шага есть короткое объяснение, индикатор прогресса, кнопки «Назад» и «Далее», а также действие, которое сразу открывает каталог виджетов, вкладку оформления или переключатель рабочих пространств. При открытии оформления гайд ставится на паузу и после закрытия настроек продолжается со следующего шага. Окно показывается только один раз; его можно закрыть в любой момент. Чтобы посмотреть гайд позже, откройте **Настройки → Рабочий стол → Знакомство с Startspace** и нажмите **«Показать знакомство повторно»**. Эта команда не меняет виджеты, тему и другие параметры.

### Командная палитра

Нажмите **Ctrl+K**, чтобы открыть поиск быстрых действий. Палитра умеет открывать каталог виджетов, настройки, темы, собственные цвета, обои, рабочие пространства и панель сайтов, а также повторно запускать знакомство. Для быстрого управления рабочим столом доступны команды: **переключить фокус-таймер**, **добавить задачу** с установкой курсора в поле, **обновить RSS-ленту**, **обновить погоду**, **обновить загрузку ПК**, **заполнить экран мозаикой** и **переключить компактный режим панели**. Команды обновления открывают первую соответствующую карточку и используют её собственную кнопку обновления; если карточка отсутствует или запрос уже выполняется, Startspace показывает понятное уведомление и не запускает лишний запрос. Введите часть названия нужного действия, используйте стрелки **↑/↓**, затем **Enter** для выполнения. Клавиши **Tab** и **Shift+Tab** перемещают фокус только внутри палитры; **Esc** закрывает её и возвращает фокус к элементу, с которого она была открыта. Статусные уведомления объявляют результат действия, а их декоративные символы не дублируются в средствах чтения с экрана. Во всех темах клавиатурный фокус отмечается кольцом в акцентном цвете.

| Вкладка | Для чего нужна |
|---|---|
| Темы, Мои цвета, Обои | Выбор основы оформления, точная палитра и фон новой вкладки. |
| Рабочий стол | Раскладка виджетов, вид интерфейса, анимации, нижняя панель и поиск. |
| Пространства | Создание, переименование и переключение независимых рабочих столов. |
| Панель сайтов | Появление, внешний вид, погода, состав мини-виджетов, перенос и проверка выдвижной панели. |
| Перенос | Экспорт и импорт макета, одного виджета или темы. |
| Проверка | Состояние сервисов и запрос разрешений только при необходимости. |

### Темы

Startspace содержит 14 встроенных тем. Геометрия виджетов и порядок элементов во всех темах одинаковы; различаются только палитра и акцентные цвета.

| Семейство | Темы |
|---|---|
| Авторские палитры | Полночный синий, Хвойная ночь, Глубокий океан, Фиолетовые сумерки, Медный уголь, Тёплый пергамент. |
| Терминал | Зелёный терминал. |
| Цветовые сигналы | Синий, Лазурный, Фиолетовый, Розовый, Красный, Оранжевый и Жёлтый сигнал. |

Акцентные кнопки во всех встроенных темах используют отдельный контрастный цвет текста. В частности, фиолетовый сигнал применяет более глубокий акцент и светлый текст, чтобы подписи активных кнопок оставались отчётливо читаемыми.

### Цвета и обои

| Параметр | Действие |
|---|---|
| Мои цвета | Переопределяет основной фон, поверхности, текст и акцент выбранной темы. |
| Тип обоев | Градиент темы, сплошной цвет или изображение. |
| Изображение | URL изображения либо локальный PNG, JPEG, WEBP или GIF до 12 МБ. Локальный файл оптимизируется перед сохранением. |
| Положение и масштаб | Настройка размещения изображения и режимов «Заполнить экран», «Поместить целиком» или «Исходный размер». |

### Рабочий стол

| Настройка | Действие |
|---|---|
| Привязывать виджеты к сетке | При ручном перемещении и изменении размера используются шаги сетки. |
| Заблокировать перемещение и размер | Защищает карточки от случайного перемещения и изменения размера. |
| Автоподгонять виджеты на рабочем столе | Адаптирует полностью автоматическую мозаику к размеру рабочей области. |
| Режим презентации | Оставляет только содержимое виджетов: служебные заголовки, свёрнутые карточки и ручки размера скрываются. |
| Скруглять границы интерфейса | Включает глобальные скругления; рядом доступна их точная величина. |
| Уменьшить анимацию | Убирает или ослабляет декоративное движение интерфейса. |
| Скорость анимаций | Полное отключение, быстрый, обычный или медленный темп появления, смены рабочих столов и мозаики. |
| Параллакс иконок при смене рабочего стола | Выбор пресета «Плавное», «Сбалансированное», «Резкий старт» или режима собственной кривой. |
| Своя кривая Безье | Доступна в режиме собственной кривой. Укажите CSS-значение, например `cubic-bezier(0.16, 1, 0.3, 1)`; первая и третья координаты должны быть от 0 до 1. |
| Шаг сетки | Точная величина шага привязки. |

### Панель сайтов

На обычных сайтах Startspace может показывать выдвижную панель с самостоятельным набором мини-виджетов. Она наследует текущую тему основной новой вкладки.

| Настройка | Диапазон или действие |
|---|---|
| Скрыть выдвижную панель на сайтах | Временно отключает появление панели, не удаляя её данные. |
| Край появления | Левый или правый край окна. |
| Ширина панели | От 280 до 420 пикселей. |
| Материал панели | **Непрозрачная** для цельной панели, **Прозрачная** для чистого фона без размытия, **Blur** для размытого стекла и **Акрил** для насыщенного стекла с акцентным оттенком. |
| Прозрачность | Точный ползунок от 0 до 65 процентов сохраняется для режимов «Прозрачная», «Blur» и «Акрил». В непрозрачном режиме он отключён. |
| Город для погоды | Город, используемый погодным мини-виджетом панели. |
| Масштаб панели | От 80 до 130 процентов. |
| Размер текста | От 80 до 160 процентов. |
| Состав виджетов | Часы, задачи, заметка, таймер, секундомер, управление воспроизведением, погода, переводчик и отдых. Выбор хранится отдельно для активного рабочего стола. |
| Перенос панели | Экспорт и импорт JSON-файла с настройками, темой, составом, порядком и высотами карточек, заметкой, задачами и состояниями таймера. |
| Мои настройки виджетов и темы | Отдельный JSON-пакет с темой, цветами, обоями, названиями, свойствами и содержимым совпадающих виджетов. При импорте не меняет позиции, размеры, сворачивание, рабочие пространства и виджеты, которых нет в пакете. |

На странице сайта наведите курсор к выбранному краю окна, чтобы открыть панель. Во время перетаскивания карточек панель удерживается открытой. Для скрытия можно использовать кнопку закрытия или клавишу **Esc**.

Если для текущего рабочего стола в панели не выбрано ни одной карточки, отображается информативное состояние **«Нет выбранных карточек»** с кнопкой **«Настроить панель»**. Она открывает новую вкладку Startspace сразу в разделе **«Панель сайтов»**, где можно включить нужные мини-виджеты.

### Проверка

Вкладка диагностики показывает состояние источников и разрешений. Для панели сайтов доступна отдельная диагностическая секция: она показывает последние результаты внедрения панели во вкладки и состояние контентной панели, а также позволяет повторно отправить панель в открытые вкладки.

Если виджет **«Загрузка ПК»** или **«Управление воспроизведением»** просит доступ, воспользуйтесь кнопкой **«Разрешить»** в диагностике и подтвердите запрос браузера.

### Перенос и резервная копия

| Операция | Содержимое |
|---|---|
| Экспортировать JSON | Полный макет: виджеты, позиции, размеры, оформление, общие настройки и состояние рабочего стола. |
| Импортировать JSON | Полностью заменяет текущий макет и общие настройки данными из файла. |
| Импортировать виджет | Добавляет один ранее экспортированный виджет в текущий рабочий стол. |
| Скачать тему | Сохраняет текущую тему и пользовательские цветовые настройки. |
| Импортировать тему | Применяет тему из JSON-файла. |
| Экспортировать / импортировать панель | Переносит только данные панели сайтов и выбранную тему. |

## Разрешения и конфиденциальность

Данные Startspace хранятся в `chrome.storage.local` внутри профиля браузера. Некоторые функции запрашивают разрешение только при использовании.

| Возможность | Для чего нужен доступ |
|---|---|
| Загрузка ПК | Доступ к системным API CPU, памяти и дисковому пространству. |
| Управление воспроизведением | Поиск и управление активным медиа в браузерных вкладках. |
| Панель сайтов | Внедрение интерфейса панели на поддерживаемые обычные страницы. |

Карточки, использующие внешние или системные данные, остаются информативными и без доступа к источнику. При ошибке RSS или погоды сохраняется последнее полученное содержимое и выводится понятный статус с возможностью повторить обновление. Если Chromium-браузер не предоставляет системные API, карточка **«Загрузка ПК»** показывает прочерки вместо вымышленных чисел, отмечает недоступные показатели и объясняет причину в строке состояния. Это не влияет на остальные виджеты и работу рабочего стола.

## Обновление и устранение проблем

После изменения файлов или получения новой версии откройте страницу управления расширениями вашего браузера, включите режим разработчика и нажмите **Reload / Перезагрузить** у Startspace. Затем обновите новую вкладку и при необходимости обычную страницу, на которой используется панель сайтов.

Если на уже открытой странице отображается старая версия панели сайтов, перезагрузите расширение, обновите страницу и откройте **Настройки → Панель сайтов → Отладка появления панели**. В этом разделе можно проверить статус и повторно отправить панель во вкладки.

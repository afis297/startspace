# Startspace

**Startspace** — расширение Chromium, которое заменяет стандартную страницу новой вкладки на настраиваемый рабочий стол с виджетами. Проект написан на чистом JavaScript с ES-модулями, без сборщика и фреймворков. Макет, настройки и данные виджетов сохраняются локально в профиле браузера.

> Полное руководство по интерфейсу, виджетам, панели сайтов и всем настройкам находится в [документации пользователя](./docs/user-guide.md).

## Основные возможности

| Область | Что доступно |
|---|---|
| Рабочий стол | Свободное перемещение, изменение размеров, сворачивание, дублирование, удаление и порядок слоёв виджетов. |
| Автоматическая мозаика | Готовые наборы, авторасстановка и автоподгонка полностью автоматической мозаики к доступной области. |
| Виджеты | 24 типа карточек: продуктивность, данные, инструменты, игры, отдых, поиск и управление воспроизведением. |
| Оформление | 14 тем, пользовательские цвета, градиенты, обои, глобальные скругления и режим презентации. |
| Панель сайтов | Выдвижная панель на обычных страницах с собственным набором мини-виджетов, масштабом, шириной и прозрачностью. |
| Перенос данных | Экспорт и импорт полного макета, отдельных виджетов, темы и панели сайтов в JSON. |
| Диагностика | Проверка разрешений, системных источников, внедрения панели сайтов и повторная отправка панели во вкладки. |

## Быстрый запуск и обновление

1. Откройте страницу управления расширениями в Chromium-браузере, например `vivaldi://extensions` или `chrome://extensions`.
2. Включите **режим разработчика**.
3. Нажмите **Load unpacked / Загрузить распакованное расширение** и выберите папку проекта, либо нажмите **Reload / Перезагрузить** у уже установленного Startspace.
4. Откройте новую вкладку.

После изменения файлов снова нажмите **Reload** у расширения. Для обновления выдвижной панели на уже открытом обычном сайте обновите и саму страницу.

## Структура проекта

```text
src/
  app/        # запуск, Store, сохранение, фоновый модуль, геометрия
  widgets/    # реестр и определения виджетов
  ui/         # рабочий стол, нижняя панель, свойства, настройки
  overlay/    # выдвижная панель Startspace на обычных сайтах
  services/   # разрешения, сетевые данные, медиа и системные метрики
  themes/     # пресеты тем и цветовые контракты
  styles/     # базовые токены, каркас, виджеты и финальная полировка

docs/         # пользовательское руководство и технические материалы
```

## Проверки

Требуется Node.js 22 (см. `.nvmrc`). Зависимостей для установки нет.

```powershell
npm test          # базовые смоуки (8 файлов)
npm run test:all  # все запускаемые без браузера смоуки (18 файлов)
.\validate-project.ps1
.\audit-project.ps1
```

Смоуки с суффиксом `-live` и `browser-smoke` требуют Deno и настоящий браузер и в CI не гоняются.

## Сборка

```powershell
.\build-extension.ps1              # chrome + firefox
.\build-extension.ps1 -Target chrome
```

Готовые архивы падают в `dist/` (не tracked, см. `.gitignore`).

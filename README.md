# 🎨 My Free Layout Tab

Кастомизируемая стартовая страница для браузера с виджетами, погодой, задачами, таймером и многим другим.

![License](https://img.shields.io/badge/license-MIT-green)
![Browser](https://img.shields.io/badge/browser-Chrome%20%7C%20Edge-orange)

## 📋 Описание

**My Free Layout Tab** — это расширение для браузера, которое заменяет стандартную новую вкладку на полностью настраиваемую страницу с виджетами. Вы можете свободно размещать виджеты на экране, изменять их размер, стиль и функциональность.

### ✨ Основные возможности

- 🎯 **Свободное размещение виджетов** - перетаскивайте виджеты в любое место экрана
- 📐 **Изменение размера** - настраивайте размер каждого виджета под свои нужды
- 🎨 **Полная кастомизация** - цвета, прозрачность, шрифты, эффекты размытия
- 💾 **Автосохранение** - все настройки сохраняются автоматически
- 🖼️ **Кастомные обои** - загрузите свое изображение фона
- 📦 **Dock-панель** - быстрый доступ к свернутым виджетам
- 🌐 **Мультиязычность** - поддержка русского и английского языков

## 🔧 Основные функции в script.js

### 📦 Конфигурация и схемы

- **`SETTINGS_SCHEMA`** - схема глобальных настроек приложения
- **`WIDGET_STYLE_SCHEMA`** - схема стилей виджетов
- **`WIDGET_TYPES`** - определения всех типов виджетов

### 🎨 Управление виджетами

- **`createWidgetDOM(config)`** - создание DOM-элемента виджета
- **`removeWidgetDOM(widgetId)`** - удаление виджета из DOM
- **`applyWidgetStyle(config)`** - применение стилей к виджету
- **`ensureStyle(widget)`** - проверка и инициализация стилей виджета

### 🖱️ Drag & Drop

- **`initDragResize()`** - инициализация перетаскивания и изменения размера виджетов
- **`initDraggableWindows()`** - перетаскивание окон настроек и меню
- **`constrainToScreen(element)`** - ограничение элемента границами экрана
- **`calculateSnapEdges()`** - расчет точек прилипания к краям

### ⚙️ Настройки

- **`initSettingsPanel()`** - инициализация панели настроек
- **`initGlobalSettings()`** - инициализация глобальных настроек
- **`saveSettings()`** - сохранение настроек в storage
- **`saveWidgets()`** - сохранение состояния виджетов

### 🪟 Управление окнами

- **`showContextMenu(widgetId, x, y)`** - показ контекстного меню виджета
- **`hideContextMenu()`** - скрытие контекстного меню
- **`initMenu()`** - инициализация меню добавления виджетов
- **`addWidget(type)`** - добавление нового виджета

### 📦 Dock-панель

- **`renderDock()`** - отрисовка Dock с свернутыми виджетами
- **`applyDockAutoHide()`** - применение автоскрытия Dock
- **`applyDockPosition()`** - применение позиции Dock (верх/низ/лево/право)
- **`initDockDrag()`** - перетаскивание Dock

### 🌤️ Погода

- **`fetchWeatherFromSources(city)`** - получение погоды из нескольких источников
- **`initWeatherWidget(config)`** - инициализация виджета погоды
- **`WEATHER_SOURCES`** - конфигурация источников погоды:
  - Open-Meteo (бесплатно, без ключа)
  - wttr.in (бесплатно, без ключа)
  - OpenWeatherMap (требует API ключ)
  - WeatherAPI (требует API ключ)

### 💱 Валюты

- **`fetchAllCurrencies()`** - получение курсов валют
- **`updateCurrencyDisplays()`** - обновление отображения валют
- **`initCurrencyWidget(el)`** - инициализация виджета валют

### ⏱️ Таймеры и часы

- **`updateClocks(timestamp)`** - обновление всех часов
- **`updateTimers(timestamp)`** - обновление таймеров и секундомеров
- **`startGlobalAnimationLoop()`** - главный цикл анимации
- **`playAlarmSound(type)`** - воспроизведение звука будильника
- **`formatTime(ms, showMs)`** - форматирование времени

### ✅ TODO-виджет

- **`initTodoWidget(el, config)`** - инициализация виджета задач
- Поддержка приоритетов (высокий/средний/низкий)
- Фильтры (все/активные/выполненные)
- Прогресс-бар выполнения

### 🎮 Игры

- **`initGameWidget(el, config)`** - инициализация игрового виджета
- **`initSnakeGame(container)`** - игра Змейка
- **`init2048Game(container)`** - игра 2048

### 🖼️ Обои

- **`applyWallpaperFromBase64(base64)`** - применение обоев из base64
- **`applyWallpaperTransform()`** - применение трансформации обоев
- **`initWallpaperUpload()`** - инициализация загрузки обоев

### 🎯 Утилиты

- **`snapToGrid(val)`** - привязка к сетке
- **`hexToRgba(hex, alpha)`** - конвертация цвета
- **`debouncedSave()`** - отложенное сохранение
- **`showConfirm(title, text)`** - кастомный диалог подтверждения

## 🚀 Установка

### Вариант 1: Из исходников

1. Скачайте или клонируйте репозиторий
2. Откройте Chrome/Edge и перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode)
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `my-newtab`

### Вариант 2: Применение исправлений

Если у вас уже установлена старая версия:

1. Откройте файл `ALL_FIXES.js`
2. Скопируйте содержимое
3. Откройте `script.js`
4. Замените функции `showContextMenu` и `initDraggableWindows` на версии из `ALL_FIXES.js`
5. Сохраните файл
6. Перезагрузите расширение в браузере

Подробные инструкции в файле `FINAL_FIX_INSTRUCTIONS.md`

## 🎨 Кастомизация

### Изменение цветовой схемы

Отредактируйте переменные в `style.css`:
```css
/* Основные цвета */
background: rgba(30, 30, 46, 0.96);  /* Фон окон */
color: #cdd6f4;                       /* Основной текст */
accent: #89b4fa;                      /* Акцентный цвет */
```

### Добавление нового виджета

1. Добавьте определение в `WIDGET_TYPES`:
```javascript
myWidget: {
    label: 'Мой виджет',
    icon: '🎯',
    category: 'productivity',
    defaultSize: { w: 200, h: 150 },
    render: (config) => `<div>Содержимое</div>`
}
```

2. Создайте функцию инициализации:
```javascript
function initMyWidget(el, config) {
    // Логика виджета
}
```

3. Добавьте вызов в `createWidgetDOM()`:
```javascript
if (config.type === 'myWidget') initMyWidget(el, config);
```

## 🐛 Известные проблемы и решения

### Окна выходят за границы экрана
✅ **Решено** - используйте исправленные функции из `ALL_FIXES.js`

### Меню виджетов слишком длинное
✅ **Решено** - добавлена прокрутка и возможность изменения размера

### Погода не загружается
- Проверьте подключение к интернету
- Убедитесь, что город написан правильно
- Попробуйте добавить API ключи для OpenWeatherMap или WeatherAPI

## 📊 Производительность

- **Размер расширения**: ~150 KB
- **Потребление памяти**: ~20-30 MB
- **Использование CPU**: минимальное (только при анимациях)
- **Оптимизации**:
  - Debounced сохранение (1 секунда)
  - RequestAnimationFrame для анимаций
  - Blob URL для обоев (вместо base64 в памяти)
  - Кэширование курсов валют (5 минут)

## 🔐 Безопасность

- Все данные хранятся локально в Chrome Storage
- Нет отправки данных на внешние серверы
- API ключи погоды хранятся локально
- Обои конвертируются в Blob URL для экономии памяти

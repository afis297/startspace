## Ключевые компоненты в script.js

### 1. Конфигурация (строки 1-260)
*   `SETTINGS_SCHEMA` - схема глобальных настроек
*   `WIDGET_STYLE_SCHEMA` - схема стилей виджетов
*   `WIDGET_TYPES` - определения 15 типов виджетов

### 2. Глобальное состояние (строки 261-280)
*   `widgets[]` - массив всех виджетов
*   `globalSettings{}` - глобальные настройки
*   `activeWidgetId` - ID активного виджета

### 3. Управление данными (строки 281-330)
*   `saveWidgets()` - сохранение виджетов
*   `saveSettings()` - сохранение настроек
*   `debouncedSave()` - отложенное сохранение

### 4. Стили и визуализация (строки 331-450)
*   `applyWidgetStyle()` - применение стилей
*   `updateAutoFontSize()` - автоматический размер шрифта
*   `applyWallpaperTransform()` - трансформация обоев

### 5. Погода (строки 451-650)
*   `WEATHER_SOURCES` - 4 источника погоды
*   `fetchWeatherFromSources()` - получение данных
*   `initWeatherWidget()` - инициализация виджета

### 6. Анимации (строки 651-850)
*   `startGlobalAnimationLoop()` - главный цикл
*   `updateClocks()` - обновление часов
*   `updateTimers()` - обновление таймеров

### 7. Валюты (строки 851-920)
*   `fetchAllCurrencies()` - получение курсов
*   `updateCurrencyDisplays()` - обновление отображения
*   `initCurrencyWidget()` - инициализация

### 8. Таймеры (строки 921-1150)
*   `playAlarmSound()` - звуковые уведомления
*   `formatTime()` - форматирование времени
*   `initTimerWidget()` - инициализация таймера

### 9. TODO (строки 1151-1400)
*   `initTodoWidget()` - список задач
*   Приоритеты и фильтры
*   Прогресс-бар

### 10. Калькулятор (строки 1401-1600)
*   `initCalculatorWidget()` - калькулятор
*   Поддержка клавиатуры и нумпада

### 11. Календарь (строки 1601-1700)
*   `initCalendarWidget()` - календарь
*   Навигация по месяцам

### 12. Игры (строки 1701-2000)
*   `initSnakeGame()` - игра Змейка
*   `init2048Game()` - игра 2048

### 13. Виджеты (строки 2001-2200)
*   `createWidgetDOM()` - создание виджета
*   `removeWidgetDOM()` - удаление виджета

### 14. Drag & Drop (строки 2201-2350)
*   `initDragResize()` - перетаскивание виджетов
*   `calculateSnapEdges()` - прилипание к краям
*   `constrainToScreen()` - ограничение границами

### 15. Настройки (строки 2351-2650)
*   `initSettingsPanel()` - панель настроек
    *   ✨ **Добавлен блок Импорт/Экспорт** с кнопками и скрытым input
    *   ✨ **Исправлено нарушение CSP**: использование `addEventListener` вместо inline `onclick`
*   `initWidgetStyleMenu()` - меню стилей
*   `initGlobalSettings()` - глобальные настройки

### 16. Окна (строки 2651-2950)
*   `initDraggableWindows()` - перетаскивание окон
*   `showContextMenu()` - контекстное меню
*   `hideContextMenu()` - скрытие меню

### 17. Dock (строки 2951-3150)
*   `renderDock()` - отрисовка Dock
*   `applyDockAutoHide()` - автоскрытие
*   `applyDockPosition()` - позиционирование

### 18. Меню виджетов (строки 3151-3350)
*   `initMenu()` - меню добавления
*   `addWidget()` - добавление виджета

### 19. Импорт / Экспорт (строки 3351-3400) ✨ НОВОЕ
*   `window.exportData()` - экспорт всех данных (виджеты, настройки, обои, ключи API) в JSON файл.
*   `window.importData(input)` - импорт данных из JSON файла с подтверждением перезаписи.

## Зависимости

### Внешние API
*   Open-Meteo - погода (бесплатно)
*   wttr.in - погода (бесплатно)
*   OpenWeatherMap - погода (требует ключ)
*   WeatherAPI - погода (требует ключ)
*   ExchangeRate-API - курсы валют (бесплатно)

### Браузерные API
*   Chrome Storage API
*   Canvas API (для игр)
*   Web Audio API (для звуков)
*   Drag and Drop API
*   RequestAnimationFrame API
*   FileReader API (для импорта файлов)
*   Blob & URL APIs (для экспорта файлов)

## Последние изменения (v4.1)
1.  **Импорт/Экспорт**: Добавлена возможность полного резервного копирования конфигурации в JSON файл.
2.  **CSP Fix**: Убраны inline-обработчики событий (`onclick`, `onchange`) из динамически генерируемого HTML в `initSettingsPanel`. Теперь используются `addEventListener`, что соответствует требованиям Manifest V3 Content Security Policy.
3.  **UI**: Добавлена новая секция "Резервное копирование" в панель настроек с кнопками Экспорт/Импорт.
